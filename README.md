# Calculadora em Python

Projeto desenvolvido em Python para a prática 01 referente a aula de DevVops

## Funcionalidades

-  Adição (+)
- Subtração (-)
- Multiplicação (*)
- Divisão (/)

## Tecnologias Utilizadas

- Python versão 3.11.1

## Como executar o projeto

1) Clonar o repositório

``````
git clone https://github.com/Yan-Cunha21/pratica_devvops.git
``````

2) Entre na pasta do projeto

``````
cd pratica01_devvops
``````

3) Execute a calculadora no terminal
``````
python app.py
ou
ctrl + f5
``````
